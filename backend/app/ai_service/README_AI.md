# AI Service for Parking Detection

Модуль для анализа изображений с камер наблюдения и определения:
1. Количества свободных парковочных мест
2. Класса автомобилей (A/B/C/D/PICKUP) на занятых местах

## Требования к модели

Согласно техническому заданию (README.md v1.2):

### Функциональные требования:
- **Распознавание свободных мест**: определение количества свободных мест на парковке
- **Классификация автомобилей**: распределение по классам `A/B/C/D/PICKUP`
- **Анализ видеоряда и фотографий**: работа со скриншотами с камер наблюдения
- **Интеграция с ingestion API**: обработка данных из `/test/screenshots` и `/test/batch-screenshots`

### Нефункциональные требования:
- **Производительность**: p95 обработки <= 2 сек (в составе общего поиска)
- **Надежность**: частичная недоступность данных не ломает ответ
- **Актуальность**: поддержка обновления данных до 1 раза в минуту

## Архитектура решения

### Этап 1 (MVP - текущий):
- Эвристический анализ / ручной ввод через `free_*` поля
- Базовая детекция наличия автомобилей

### Этап 2 (Pilot Production):
- CV/ML пайплайн для детекции авто и парковочных промежутков
- Модель классификации автомобилей по классам
- Детекция свободных парковочных мест

### Этап 3 (Scale):
- Вынос в отдельный worker
- Очереди задач для обработки
- SLA/SLO мониторинг

## Рекомендуемые технологии

### Для этапа MVP (Эвристика):
- OpenCV для базовой обработки изображений
- Простые эвристики по цвету/текстуре для определения занятости мест

## Интеграция с backend

### API контракты:

#### Входные данные (из ingestion):
```python
{
    "camera_id": str,
    "image_data": bytes,  # или путь к файлу
    "timestamp": datetime,
    "location": {"lat": float, "lon": float}
}
```

#### Выходные данные (для aggregation):
```python
{
    "total_spaces": int,      # Всего мест
    "free_spaces": int,       # Свободные места
    "occupied_spaces": int,   # Занятые места
    "vehicle_classes": {
        "A": int,             # Количество машин класса A
        "B": int,             # Количество машин класса B
        "C": int,             # Количество машин класса C
        "D": int,             # Количество машин класса D
        "PICKUP": int         # Количество pickup
    },
    "confidence": float,      # Общая уверенность модели
    "processing_time_ms": int # Время обработки
}
```
